# Ghostab

Ghostab is a tiny experimental browser built around Ghost Engine, a small
browser-engine experiment written in Rust.

## Features

- Never collects any data
- Does not use Blink or Gecko as a base
- Isolated clipboard
- Old-styled but simple UI
