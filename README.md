# Ghostab

Ghostab is a tiny experimental browser built around Ghost Engine, a small
browser-engine experiment written in Rust.

## Features

- Never collects any data
- Does not use Blink or Gecko as a base
- Isolated clipboard
- Old-styled but simple UI

## Download

### Linux

#### Debian (recommended)

1. Downlod the `.deb` package from releases or from [the official site](https://aramczdev.github.io/ghostab)
2. Open your terminal and write
```bash
sudo apt install (path to your .deb)
```
3. Run `ghostab` and Ghostab will open

#### Flatpak

1. Downlod the `.flatpak` package from releases or from [the official site](https://aramczdev.github.io/ghostab)
2. Open your terminal and write
```bash
flatpak install (path to your file)
```
3. Run `flatpak run io.github.aramcz.ghostab` and Ghostab will open


### Windows

1. Download the .exe file
2. Open it
3. If you see a warning click View More and Run Anyway then Ghostab will open

### MacOS

- Support for Ghostab is not planned
