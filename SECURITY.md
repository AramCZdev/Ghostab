# Security Policy

## Supported Versions

| Version     | Supported          |
| ----------- | ------------------ |
| Latest      | :white_check_mark: |
| Any Older   | :x:                |

## Reporting a Vulnerability

For Reporting a Vulnerability don't use Github Issues and instead contact me via [Email](mailto:aramcz@protonmail.com)

### Please include:

- A description of the vulnerability
- Steps to reproduce it
- Any relevant screenshots, logs, or proof-of-concept information

### Make Sure

- This is on the latest version of Ghostab
- This isn't some random issue
